# Security policy

Please report security issues privately before opening a public issue. Until a dedicated security address is published, use GitHub's private vulnerability reporting for the repository.

Catway does not require network access and does not collect telemetry. Its integration tools may hold macOS Accessibility permission; review the installed scripts under `~/.config/catway` and grant permissions only to applications installed from sources you trust.

Only the latest tagged release receives security fixes during the `0.x` period.
